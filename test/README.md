# 🚀 T1 HR-Case RecSys — Полное руководство по установке и развертыванию

Данный проект — это рекомендательная система подбора и скоринга резюме под вакансии (кейс T1) на базе **FastAPI**, **PostgreSQL + pgvector**, **Redis**, **MongoDB**, **Sentence-Transformers**, **Implicit ALS** и **React**.

---

## 💡 Главный секрет: Зачем нужен Docker?

Вам **НЕ нужно** вручную устанавливать на свой компьютер:
* ❌ Отдельный сервер PostgreSQL
* ❌ Компилировать и настраивать расширение `pgvector` под Windows (что требует Visual Studio C++ компиляторов)
* ❌ Искать и устанавливать сервер Redis под Windows
* ❌ Устанавливать MongoDB Server
* ❌ Настраивать совместимость версий Python и Node.js

Все эти 5 сервисов уже упакованы в контейнеры внутри файла `docker-compose.yml`. Вам достаточно установить **только одну программу — Docker Desktop**, и проект развернется автоматически в одну команду!

## 🛠 ЧАСТЬ 1: Установка необходимых инструментов на домашний ПК с Windows

### Шаг 1. Установка Docker Desktop

Есть два простых способа:

#### Вариант А (Через консоль — быстрее всего):
Откройте **PowerShell от имени Администратора** (клик правой кнопкой по «Пуск» $\rightarrow$ «Терминал (Администратор)» или «PowerShell (Администратор)») и выполните:
```powershell
winget install --id Docker.DockerDesktop -e
```

#### Вариант Б (Через браузер):
1. Перейдите на официальный сайт: [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/)
2. Нажмите **"Download for Windows"** (файл `Docker Desktop Installer.exe`, ~500 МБ).
3. Запустите скачанный файл. В появившемся окне оставьте галочку **"Use WSL 2 instead of Hyper-V (recommended)"** и нажмите **OK**.
4. Дождитесь окончания установки и нажмите **Close and restart** (если потребуется перезагрузка ПК).

---

### Шаг 2. Настройка виртуализации WSL 2 (Если Docker Desktop запросит при первом запуске)

Docker на Windows работает через легкую виртуализацию WSL 2 (Windows Subsystem for Linux). Обычно установщик настраивает её сам. Если при старте Docker Desktop выдает ошибку о WSL:

1. Откройте PowerShell и выполните:
   ```powershell
   wsl --update
   ```
2. Если WSL никогда не был включен, выполните:
   ```powershell
   wsl --install
   ```
   *(и перезагрузите компьютер).*
3. Убедитесь, что в BIOS вашего компьютера включена аппаратная виртуализация (Intel VT-x или AMD-V) — по умолчанию она включена почти на всех современных ПК.

---

### Шаг 3. Запуск Docker Desktop

1. Запустите приложение **Docker Desktop** из меню «Пуск».
2. При первом запуске примите лицензионное соглашение («Accept»).
3. Вход в аккаунт можно пропустить (**"Continue without signing in"**).
4. Дождитесь, пока в левом нижнем углу окна Docker Desktop статус станет зеленым: **"Engine running"**.

> ⚠️ **ВАЖНО:** После установки Docker Desktop **закройте и снова откройте терминал (PowerShell / VS Code)**, чтобы Windows обновила системные пути (PATH) и команда `docker` стала доступна.

## 🚀 ЧАСТЬ 2: Запуск и развертывание проекта

### Шаг 1. Перейдите в папку проекта

Откройте терминал (PowerShell или командную строку в VS Code / Antigravity):

```powershell
cd C:\T1-HR-Case\test
```

### Шаг 2. Запустите сборку и старт всех сервисов

Выполните одну команду:

```powershell
docker compose up --build
```

**Что произойдет автоматически:**
1. Docker скачает готовый образ **PostgreSQL 16 с предустановленным pgvector**.
2. Скачает быстрый образ **Redis 7** (in-memory кэш и очереди).
3. Скачает официальный образ **MongoDB 7** (хранилище сырых JSON из парсеров).
4. Автоматически соберет контейнер **бэкенда на FastAPI** (установит PyTorch, Sentence-Transformers, Implicit ALS, SQLAlchemy).
5. Автоматически соберет и запустит **React фронтенд** на порту `3000`.
6. Сервер сам выполнит `CREATE EXTENSION IF NOT EXISTS vector;` и создаст таблицы в базе данных.

> ⏳ **Первый запуск:** займет 2-4 минуты, пока скачиваются базовые образы. Все последующие запуски будут стартовать за 3-5 секунд!

   * **Кандидат 1 (Алексей Смирнов):** Senior Python разработчик с 5 годами опыта $\rightarrow$ скоринг **~90%** (высокое косинусное сходство векторов, 100% совпадение стека).
   * **Кандидат 2 (Дмитрий Кузнецов):** Junior Python разработчик, 0.5 года опыта, Django $\rightarrow$ скоринг **~45-55%** (штраф за недостаток опыта и неполный стек).
   * **Кандидат 3 (Сергей Васильев):** Старший Бариста $\rightarrow$ скоринг **< 20%** (нерелевантные эмбеддинги и 0 совпадений по стеку).

## ⚠️ Решение частых проблем (Troubleshooting)

1. **`docker : Имя "docker" не распознано...`**
   * Перезапустите терминал (PowerShell или VS Code). Переменные среды обновляются только в новых окнах терминала.
2. **`error during connect: This error may indicate that the docker daemon is not running.`**
   * Убедитесь, что приложение **Docker Desktop запущено** и значок в трее зеленый.
3. **Порт 5432 (или 6379, 8000, 3000) уже занят:**
   * Если у вас уже был локально установлен старый PostgreSQL на порту 5432, измените порт в `test/docker-compose.yml` (например, `"5433:5432"`).
4. **"Virtualization is disabled in BIOS":**
   * Перезагрузите компьютер, зайдите в BIOS (клавиша Del или F2 при включении) и включите опцию **Virtualization (VT-x / AMD-V / SVM Mode)**.
